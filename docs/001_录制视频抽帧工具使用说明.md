# 001 录制视频抽帧工具使用说明

本工具用于从录制的视频文件（支持 `.mp4`、`.avi`、`.mov`、`.mkv`、`.flv`、`.wmv`、`.ts`、`.m4v`、`.webm`）中高效抽取高质量图片帧，作为后续 **标注工作台 / 智能标注** 与 **YOLO26** 训练的源图片。

---

## 1. 启动方式

### 方式 A：图形界面（推荐）
双击项目根目录下的 `run_gui.bat`，或在终端运行：

```powershell
.venv\Scripts\python.exe main.py
```

进入界面后默认打开 **「1. 视频抽帧」** 标签页。

### 方式 B：命令行（CLI）
适合批处理脚本调用：

```powershell
.venv\Scripts\python.exe cli.py extract "D:\videos\demo.mp4" -o "data\raw_frames" --mode interval_seconds --interval 1.0 --dedup 2.0
```

---

## 2. 图形界面操作流程

1. **选择录制视频**：
   - 点击 **「添加视频文件」** / **「添加视频文件夹」**，或直接将视频文件、文件夹**拖拽到左侧列表框**中导入（文件夹会自动递归扫描支持的视频格式）。
   - 列表以两行卡片形式展示每个视频的文件名、格式化时长、分辨率、帧率（FPS）、总帧数、所属目录，以及当前策略下的**预估抽取帧数**；支持多选（`Ctrl`/`Shift`）后按 `Delete`/`Backspace` 键或右键移除。
   - 选中列表中的某个视频时，右侧画布会自动预览该视频在「截取起始时间」处的画面（可在抽帧前确认未选错片段或画面清晰度）。
2. **设置输出目录**：
   - 默认输出至项目下的 `data/raw_frames`，可根据项目需要修改。
   - 支持中文路径与文件名。
3. **选择抽帧策略**：
   - **按时间间隔抽帧 (`interval_seconds`)**：每隔固定秒数抽取 1 帧（例如 `1.0` 秒，适合常规监控或手持录制视频）。
   - **按固定帧步长抽帧 (`every_n_frames`)**：每隔固定帧数抽取 1 帧（例如每 `30` 帧抽 1 帧）。
   - **按目标总帧数均匀抽帧 (`target_count`)**：按视频总时长均匀抽取指定张数（例如每个视频固定抽 `100` 张）。
   - 切换策略时同行右侧的数值框会原地切换为「间隔 / 步长 / 目标」，并在右侧监控区实时更新预计抽取总数。
4. **截取时间段（可选）**：
   - 可设置起始秒数与结束秒数（结束设为 `0` 表示一直抽到视频结尾），跳过片头片尾无效片段；调整起始秒数时右侧预览画布会联动刷新到对应起点画面。
5. **相似帧去重**：
   - 默认值 `2.0`：计算相邻抽取帧的灰度平均像素差，若低于阈值（画面几乎静止/无变化）则自动跳过，避免标注大量重复帧（数值越大过滤越严，常用 `1.5~3.0`）。
   - 设为 `0` 可关闭去重。
6. **缩放最长边、格式与命名规则**：
   - **缩放最长边 (`0 px (原尺寸)`)**：若原视频为 4K 且只需训练 `640` 或 `1280` 尺度模型，可设为 `1280` 或 `1920` 以减小图片体积并加快标注速度。
   - **格式**：支持 `jpg`（默认质量 `95`，磁盘占用小）与 `png`（无损；选择 `png` 时「JPG质量」会自动置灰）。
   - **命名规则**（点击右侧 **「预设 ▾」** 可快速填入常用模板）：
     - **留空（默认）**：按 `vc` + 视频完整内容 SHA-256 小写十六进制前 32 位 + `_f` + 10 位帧毫秒时长命名（例如 `vc9f86d081884c7d659a2feaa0c55ad015_f0000001500.jpg`）；毫秒时长优先取视频帧真实时间戳（`CAP_PROP_POS_MSEC`），不可用时自动回退为 `round(帧号 * 1000 / fps)`。
     - **指定普通前缀**（不含占位符，如 `cam1_`）：以指定前缀为准，按 `{前缀}{视频名}_{6位序号}` 命名（如 `cam1_demo_000001.jpg`）。
     - **指定占位符模板**（如 `{video}_{seq:06d}`、`{video}_f{ms:010d}`）：以指定模板为准，可用占位符包括 `{video}`（视频名，同名自动消歧）、`{hash}`（SHA-256 前 32 位）、`{hash_full}`（完整 64 位 SHA-256）、`{ms}`（帧毫秒时长）、`{frame}`（原始帧序号，从 0 开始）、`{seq}`/`{index}`（当前视频保存序号，从 1 开始）、`{prefix}`（CLI 兼容前缀）。输入框下方会实时展示示例路径并在语法非法时拦截提示。
   - **按视频名分建子目录**：勾选后会按视频文件名分别建立子文件夹存放帧图，下方「命名示例」也会实时联动显示子目录层级。
   - 多个视频文件名相同（例如 `cam1/rec.mp4` 与 `cam2/rec.mp4`）时，默认按视频内容哈希天然区分；使用 `{video}` 占位符、普通前缀或分建子目录时，视频名键会自动改为 `上级目录名_文件名`（如 `cam1_rec`），避免不同视频的帧互相覆盖。
7. **开始抽帧与衔接标注**：
   - 点击 **「开始抽帧」** 后，右侧将实时展示最新抽取的画面缩略图、多视频全局进度条以及 4 张监控卡片（视频进度、已保存帧数、去重跳过数与跳过率、任务耗时）。
   - 抽帧完成后默认停留在当前页展示统计摘要，同时静默同步输出目录并高亮 **「发送到「2. 标注工作台」→」** 按钮；如需完成后自动切入标注工作台，可勾选 **「抽帧完成后自动进入「2. 标注工作台」」**。

## 3. 命令行参数参考 (`cli.py extract`)

| 参数 | 说明 | 默认值 |
| :--- | :--- | :--- |
| `inputs` | 一个或多个视频文件/目录路径 | 必填 |
| `-o, --output` | 抽帧图片输出目录 | `data/raw_frames` |
| `--mode` | `interval_seconds` / `every_n_frames` / `target_count` | `interval_seconds` |
| `--interval` | 时间间隔（秒） | `1.0` |
| `--step` | 帧步长（帧） | `30` |
| `--count` | 每个视频均匀抽取目标帧数 | `100` |
| `--start` | 截取起始时间（秒） | `0.0` |
| `--end` | 截取结束时间（秒，`0` 表示到视频结尾） | `0.0` |
| `--dedup` | 相似帧去重阈值（`0` 关闭；底层编程接口 `ExtractionConfig` 默认 `0.0`） | `2.0` |
| `--max-dim` | 最长边限制像素（`0` 保持原尺寸） | `0` |
| `--format` | 输出图片格式 `jpg` 或 `png` | `jpg` |
| `--quality` | JPG 压缩质量（`1..100`） | `95` |
| `--naming-rule` | 自定义命名规则（留空默认 `vc{hash}_f{ms:010d}`；可填普通前缀或占位符模板） | `""` |
| `--prefix` | 输出图片文件名前缀（兼容选项；未指定 `--naming-rule` 时生效，或在模板中以 `{prefix}` 引用） | `""` |
| `--subfolder` | 按视频名在输出目录下分建子目录 | 关闭 |
